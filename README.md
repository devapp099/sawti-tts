# صوتي — Sawti TTS

واجهة عربية متجاوبة لتحويل النص إلى كلام، والاستماع، وتنزيل **MP3 حقيقي**. تتضمن أصواتًا عُمانية وسعودية وإماراتية ومصرية وصوتًا إنجليزيًا، مع تغيير السرعة وحد أقصى 5000 حرف.

## التشغيل

يتطلب Python 3.11 أو أحدث واتصال إنترنت:

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS / Linux:
# source .venv/bin/activate
pip install -r requirements.txt
python server.py
```

افتح http://localhost:8000. اكتب النص، اختر الصوت والسرعة، اضغط «تحويل إلى صوت»، ثم استمع أو نزّل MP3. لا تفتح ملف HTML مباشرة.

## الاستضافة

هذا تطبيق Python بخادم خلفي، ولا يعمل على GitHub Pages وحدها. يمكن نشره على استضافة تدعم Python أو Docker مع اتصال صادر HTTPS/WebSocket لخدمة Microsoft. استمع إلى متغير `PORT` الذي تحدده الاستضافة، والمسار `/health` لفحص جاهزية الخادم فقط؛ لا يختبر توفر مزود الصوت.

```bash
docker build -t sawti-tts .
docker run --rm -p 8000:8000 sawti-tts
```

## مزود الصوت والخصوصية

يستخدم [edge-tts](https://github.com/rany2/edge-tts) للاتصال بخدمة Microsoft Edge الصوتية عبر الإنترنت دون مفتاح API. المكتبة ليست واجهة Microsoft تعاقدية مضمونة؛ قد يتغير توفر الخدمة والأصوات. راجع شروط مزود الخدمة قبل الاستخدام التجاري أو الإطلاق العام. لا يقدم المشروع استنساخ أصوات أو تحكمًا بالمشاعر.

يرسل النص إلى Microsoft للتوليد. لا يحفظ التطبيق النص أو MP3 على القرص؛ يجمع الصوت مؤقتًا في الذاكرة ويعيده للمتصفح. لا يعني ذلك أن المزود لا يحتفظ بالبيانات. امسح النص لإزالة النتيجة من الواجهة، ولا تدخل معلومات حساسة.

هذه نسخة أولية بخادم Python للتجربة والاستضافة المحدودة. قبل الإطلاق العام استخدم بوابة HTTPS وتحديد معدل الطلبات ومصادقة عند الحاجة. توجد حدود لطول النص وحجم الطلب والصوت وعدد العمليات المتزامنة ومهلة التوليد؛ ليست بديلًا عن تحديد الاستخدام لكل مستخدم.

## التحقق

```bash
python -m unittest discover -s tests -v
```

تختبر الاختبارات HTTP والمدخلات والأخطاء وعودة ملف MP3 بواسطة مزود وهمي؛ لا تثبت جودة صوت Microsoft أو توفره. للاختبار الفعلي بعد تثبيت المتطلبات شغّل الخادم وحوّل نصًا قصيرًا، ثم شغّل الملف المنزّل.
